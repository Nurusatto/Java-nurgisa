# Работа трёх разработчиков

1. Backend Core: безопасность, пользователи, клиенты, устройства, заказы,
   статусы, диагностика, аудит, tracking, настройки. Владеет политикой ремонта.
2. Inventory & Finance: запчасти, движения, закупки, поступления, платежи,
   возвраты, расходы, гарантии и серверные финансовые/складские отчёты.
   Владеет изменением остатков и расчётов; агрегаты по ремонтам согласует с Backend Core.
3. Desktop & Integration: JavaFX, FXML/CSS, gateway, формы, навигация,
   отчёты и уведомления в интерфейсе; серверный контур уведомлений.

Общий contracts JAR не зависит от Spring, JavaFX или JPA. Изменение DTO требует
проверки обоих потребителей. HTTP и cookie/CSRF находятся только в ApiClient,
маршруты — в FixFlowGateway, представление и обработчики событий — в контроллере.

Запись чужой предметной области выполняется через её сервис. Использование
детали блокирует заказ, затем запчасть. Поступление блокирует закупку, затем
запчасти по ID. Финансовые изменения сериализуются блокировкой заказа.
Отчёты используют SQL-проекции только на чтение в согласованном снимке БД.

Каждый PR должен собираться через `./mvnw verify`; критичные изменения сопровождаются
проверкой на PostgreSQL. Новые миграции добавляются отдельными версиями. Уже применённые
миграции не редактируются. Изменение API, миграции, интерфейс и документация входят
в один проверяемый этап. Неработающие пункты меню не добавляются для видимости полноты.
